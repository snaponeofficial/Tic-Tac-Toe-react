# Tic Tac Toe

A responsive two-player Tic-Tac-Toe game built with Next.js and TypeScript.

## Features

- Local two-player gameplay
- Win and draw detection
- Persistent scores using local storage
- Move history and undo
- Dark and light themes
- Optional sound effects
- Keyboard navigation
- Responsive layout for mobile and desktop

## Built with

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Motion for React
- Lucide React
- Vitest

## Getting started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available scripts

```bash
npm test       # Run the game logic tests
npm run lint   # Check the source with ESLint
npm run build  # Create a production build
npm start      # Run the production server
```

## Deployment

The project can be deployed to Vercel with the default Next.js settings. It does not require environment variables or a backend service.
